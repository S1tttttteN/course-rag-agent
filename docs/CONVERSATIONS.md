# 对话、引用与流式运行

## 使用

每门课程可以创建、重命名、切换和删除多段对话。输入首个问题可自动创建对话；切换课程不会复用其他课程的上下文。模型在后端 `.env` 配置，页面不接收密钥。

固定 RAG 每次先执行课程检索再生成，不主动联网。Agent 自主选择查阅步骤，可在「回答设置」中允许联网。默认自然讲解，允许知识补充和举例，补充内容应与课程原文区分。两种模式都可以在页面开启[生成后证据核对](EVIDENCE_CHECK.md)。

回答支持 Markdown、表格、代码块和 `[n]` 引用。页面不执行 Markdown 原始 HTML，不自动加载外部图片，代码块内的编号不转换为引用。

## 上下文

后续问题使用最近三轮已完成问答，每轮问题和回答各最多 2000 字符。有资料的 RAG 追问会尝试改写为独立检索问题；改写失败使用上一问题辅助检索。对话只帮助理解指代，不能替代当前来源。

失败、取消和服务中断的内容仍可回看，但不作为完整历史使用。对话删除会移除消息、运行、事件及引用，保留课程资料；删除课程会移除关联资料和对话。

## 引用快照

点击回答中的引用编号或「参考来源」后，桌面右侧显示该轮来源和选中的原文摘录。窄屏从底部打开同一阅读面板。关闭后可以继续读回答或提问。

后端从工具实际取得的内容注册统一编号，重复片段复用编号。课程来源保存文件名、资料版本、原文位置和真实存在的 PDF 页码；网络来源保存 URL、抓取时间、摘要/正文类型和摘录。

打开课程引用时显示来源仍在使用、已更新或已删除。原资料变化后仍能查看回答当时的快照。网络摘录不是完整网页，页面内容可能变化。

无法匹配的编号不会生成伪来源链接。编号注册正确不证明某句结论得到原文支持，需要阅读片段核对。

## 执行与恢复

每个问题对应一次 Run、一条用户消息及一条助手消息。页面通过 SSE 展示状态、查阅记录和回答增量，按事件 ID 恢复连接。停止保留已经发布的部分，标记为取消。重启后未完成运行标为中断，不自动重放模型请求。

本地 Ollama 最多并发一轮，其他对话服务最多两轮；每段对话最多一个活动 Run，活动任务总数最多六个。整轮超时由 `RUN_TIMEOUT` 决定，排队等待不计入执行预算。具体模型工厂还设有单次请求和输出限制。

API 详情以运行中的 `/docs` 为准，配置见 [CONFIGURATION.md](CONFIGURATION.md)。
