# 对话、引用与流式运行

## 使用

每门课程可以创建、重命名、切换和删除多段对话。输入首个问题可自动创建对话；切换课程不会复用其他课程的上下文。模型在后端 `.env` 配置，页面不接收密钥。

固定 RAG 每次先执行课程检索再生成，不主动联网。Agent 自主选择查阅步骤，可在「回答设置」中允许联网。默认自然讲解，允许知识补充和举例，补充内容应与课程原文区分。两种模式都可以在页面开启[生成后证据核对](EVIDENCE_CHECK.md)。

回答支持 Markdown、表格、代码块和 `[n]` 引用。页面不执行 Markdown 原始 HTML，不自动加载外部图片，代码块内的编号不转换为引用。

## 上下文

后端从同一会话的已完成问答与 Agent 检查点构造上下文。首次使用或打开没有检查点的旧对话时，从最近的完整问答中装载约 6,000 token。页面仍展示完整的聊天记录。

Agent 在每轮开始时使用 LangChain 的摘要中间件。历史连同本轮问题达到约 4,000 token 或 9 条消息时尝试压缩旧消息，保留约 1,800 token 的近期内容和完整的本轮问题。摘要随成功回答保存到数据目录的 `agent_checkpoints.sqlite3`。固定 RAG 可以用该摘要和近期已完成问答改写追问，回答仍使用本轮来源作为依据。纯 RAG 会话使用近期历史窗口。

失败、取消和服务中断的内容仍可回看，后续问答只使用已完成记录。删除会话会移除消息、运行、事件和引用，并由后台清理对应检查点。删除课程会同时清理所有关联会话的检查点。

## 引用快照

点击回答中的引用编号或「参考来源」后，桌面右侧显示该轮来源和选中的引用摘录。窄屏从底部打开阅读面板。对 PDF 引用，选择「查看第 N 页」会跳到回答时使用的版本和页码，再向上或向下滚动可阅读相邻页面。桌面浮窗支持拖动、拉伸、最大化和还原。浮窗外的问答和摘录仍可操作。窄屏在底部面板阅读，关闭后返回摘录。没有页码时从第一页打开，原件已删除时仍可查看摘录。

后端从工具实际取得的内容注册统一编号，重复片段复用编号。课程来源保存文件名、资料版本、原文位置和真实存在的 PDF 页码；网络来源保存 URL、抓取时间、摘要/正文类型和摘录。

对 TXT 和 Markdown 引用，选择「定位原文」打开回答时使用的版本。TXT 跳到摘录起始行并高亮摘录，Markdown 高亮对应的可见内容块。位置无法确认时，阅读器会提示并从文档开头显示，引用摘录仍可查看。

HTML 和 DOCX 也支持「定位原文」。摘录在可见正文中唯一匹配时，高亮对应段落或表格行。出现重复摘录或预览缺少对应内容时，阅读器会提示并打开该版本。原件缺失或转换失败时仍可返回引用摘录。

打开课程引用时显示来源仍在使用、已更新或已删除。原资料变化后仍能查看回答当时的快照。网络摘录不是完整网页，页面内容可能变化。

无法匹配的编号不会生成伪来源链接。编号注册正确不证明某句结论得到原文支持，需要阅读片段核对。

## 执行与恢复

每个问题对应一次 Run、一条用户消息及一条助手消息。页面通过 SSE 展示状态、查阅记录和回答增量，按事件 ID 恢复连接。停止保留已经发布的部分，标记为取消。重启后未完成运行标为中断，不自动重放模型请求。

本地 Ollama 最多并发一轮，其他对话服务最多两轮；每段对话最多一个活动 Run，活动任务总数最多六个。整轮超时由 `RUN_TIMEOUT` 决定，排队等待不计入执行预算。具体模型工厂还设有单次请求和输出限制。

API 详情以运行中的 `/docs` 为准，配置见 [CONFIGURATION.md](CONFIGURATION.md)。
