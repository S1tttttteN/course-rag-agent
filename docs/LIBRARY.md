# 课程资料库

## 使用

进入课程，选择或拖入 TXT、MD、HTML、HTM、DOCX、可提取文字的 PDF。支持多选逐份上传，每份最多 20 MB；正文最多 200 万字符，片段最多 10000 个。图片、扫描 PDF 和 PPT 暂不支持，空正文会显示处理失败。

TXT 和 Markdown 支持 UTF-8、GB18030、Big5，以及带 BOM（字节序标记）的 UTF-16 和 UTF-32。若提示无法识别文本编码，请另存为 UTF-8 后重新上传。

上传成功只代表文件已保存。后台依次解析、分块、生成向量并发布，页面自动刷新状态。配置错误或网络失败后，可以调整根目录 .env、重启后端，再点击失败文件的重试。嵌入调用使用 30 秒请求超时、一次 SDK 重试，每批 32 个片段。

同一课程已有同名文件时，上传会被拒绝并提示使用替换。同名文件在不同课程互不影响。替换保留资料 ID 与展示名称，新文件名记录在版本中；新版本完成前继续使用旧版。处理中不允许再次替换。失败时也可再次选择文件生成下一版本。

点击「原文」可在桌面右栏或窄屏底部面板分页查看当前可用版本。PDF 显示解析所得页码。「检索试用」只展示原文。默认结合语义与 BM25，使用 RRF 融合，可以关闭语义或打开可选重排。语义或重排失败时会提示降级。

语义搜索需要当前嵌入配置与可用版本一致；切换嵌入模型后，需要逐份用原文件替换以生成新向量。配置切换期间可用关键词搜索，避免维度或语义空间混用。全部关闭语义与重排后，搜索仅在本地执行。

## 状态与一致性

- `queued`：已保存文件，等待处理。
- `processing`：解析或生成向量，记录当前步骤和进度。
- `ready`：该版本已完整写入，能被发布为当前可用版本。
- `failed`：本次处理失败；错误信息不返回密钥或模型接口响应正文。

SQLite 的 `Document.active_version_id` 决定检索可见性。SQLite 保存带来源的原文片段，Chroma 保存向量；每课程、每嵌入配置分别使用集合。BM25 缓存以课程和可用版本集合为键。

新版本的向量先写入，全部成功后才事务性写入原文并切换可用版本。失败或处理中删除时清理未发布向量，旧版保持可用。旧版本原文件和原文片段保留到整份资料删除，退休向量在发布后回收；对话引用另存独立快照。

删除资料或课程时，业务记录和独立清理任务在同一事务提交。业务记录即时不可查询；清理线程之后删除对应集合记录和原文件目录，失败任务保留并重试。文件用系统生成的 ID 存放，用户文件名只作元数据。

服务启动后将遗留 `processing` 重置为 `queued`，核对并移除未发布向量以及未提交上传的残留文件，再消费队列。关闭时先停止调度，等待当前批次结束并关闭 Chroma 句柄。仅支持单个后端进程。

## 存储

```text
data/
  app.sqlite3                 课程、资料版本、原文、清理任务
  uploads/{course}/{document}/{version}.{ext}
  course_indexes/             嵌入式 Chroma 数据库
```

## API

| 方法 | 路径（均以 /api 开始） | 用途 |
|---|---|---|
| GET | /library/config | 嵌入配置状态、上传限制及清理任务数量，不含密钥 |
| GET | /courses/{course}/documents | 当前课程资料及最新处理状态、可用版本 |
| POST | /courses/{course}/documents | multipart `file` 上传，202 表示已排队 |
| PUT | /courses/{course}/documents/{document}/file | multipart `file` 替换，生成新版本 |
| POST | /courses/{course}/documents/{document}/retry | 重试失败的最新版本 |
| DELETE | /courses/{course}/documents/{document} | 移除资料并排队清理 |
| GET | /courses/{course}/documents/{document}/preview | offset/limit 分页读取当前可用原文 |
| POST | /courses/{course}/search | query、top_k、semantic、rerank；返回原文和检索状态 |

404 表示不存在或不属于当前课程；409 表示重名、状态冲突或尚无可用版本；413 表示文件过大；422 表示请求结构或字段无效。

## 验证

后端检查覆盖格式、中文编码、HTML 清洗、PDF 多页、课程隔离、真实 Chroma 读写、版本原子发布、失败重试、处理中删除、课程级联删除、故障恢复、清理重试与后台线程处理。

故障检查使用确定性测试向量，不调用外部服务。真实服务的可用性取决于所选服务商、配置与网络。
