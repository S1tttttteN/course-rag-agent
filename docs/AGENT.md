# Agent 工具与预算

LangChain `create_agent` 将当前问题、已完成对话和工具交给模型，由模型决定查阅步骤。课程问题优先查课程资料；通用解释可以直接回答，需要拓展或最新信息时可按配置联网。

## 工具

| 工具 | 输入与用途 |
| --- | --- |
| `search_course` | 当前课程中的关键词/语义搜索，返回带编号的原文 |
| `list_documents` | 分页列出当前课程的资料名、版本和可读状态 |
| `read_document` | 使用当前课程的资料 ID、版本 ID 和偏移读取连续片段 |
| `search_web` | 公开搜索，返回至多三个带编号的摘要与 URL |
| `read_webpage` | 读取当前运行搜索返回的网页，抽取正文摘录 |

默认只提供课程工具。在「回答设置」开启「允许 Agent 联网」后，下一轮 Agent 可使用搜索和网页阅读工具。搜索摘要只反映搜索结果中的片段，核实全文需要阅读完整页面。

## 后端约束

- 课程范围由后端绑定，输入模型拒绝额外范围字段；资料必须属于当前课程且版本可用。
- 一轮最多八次工具调用，无效调用也计数；单次工具执行超时 35 秒。
- 最多保留 24 个来源，来源文本总量最多 20000 字符；搜索和阅读按分页限量。
- 网页只读取 HTTP(S) 的公开地址，检查重定向，不执行脚本；正文摘录最多 4000 字符。
- 达到工具上限时，可根据现有内容做一次无工具总结，不继续查阅。

## 来源与回答

引用编号由后端注册，模型引用已有编号。课程原文、网络摘要和网页正文分别标记。知识解释与推论允许出现，但不能伪装成已查到的课程事实。

工具输入、状态、耗时和受控摘要可在界面查看，不展示完整推理。工具错误不回传服务商异常正文。外部内容中的指令属于不可信输入，相关剩余风险见 [安全说明](../SECURITY.md)。
