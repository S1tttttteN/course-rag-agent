# 一次完整体验

先按[安装说明](GETTING_STARTED.md)配置并启动前后端，确保嵌入服务可用。

1. 创建课程“操作系统示例”。
2. 上传 `backend/evaluation/fixtures/` 下的四份 Markdown，等待全部就绪。
3. 选择固定 RAG，问“PCB 包含哪些信息？”，打开引用核对原文。
4. 切换 Agent，问“先列出课程资料，再查找实验 A 的超时阈值和异常 E4 的处理步骤，分别引用来源。”查看工具记录。
5. 继续追问，观察上下文是否正确承接，以及课程原文和一般解释是否区分。
6. 新建另一门课程，确认不会引用前一课程的资料。
7. 刷新页面，回看消息、来源和运行状态；生成过程中也可停止回答。

开启联网后，可请求 Agent 搜索官方文档并阅读其中一个结果。检查来源是否标记为搜索摘要或网页正文，不将网络补充误认为课程原文。

示例资料中的实验阈值、口令和注入标记均为虚构。使用真实课程时请自行上传有权处理的资料，并根据所选模型服务确认数据流向。
