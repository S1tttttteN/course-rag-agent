# 并排研读

课程研习室用正文和原文之间的关系组织页面。回答中的引用编号与阅读栏选中项使用同一种交互蓝。正文采用连续排版，资料和对话用紧凑列表呈现。

| CSS 变量 | 值 | 用途 |
| --- | --- | --- |
| `--canvas` | `#F5F7FA` | 课程导航和页面底色 |
| `--paper` | `#FFFFFF` | 正文、输入区和阅读栏 |
| `--ink` | `#19263A` | 标题和正文 |
| `--muted` | `#53657A` | 辅助文字和图标 |
| `--accent` | `#2454A6` | 主操作、引用和键盘焦点 |
| `--line` | `#D9E2ED` | 分隔线和控件边界 |

字体优先使用本机 Geist 和思源黑体，按系统字体回退。页面标题约 24–32 px，回答正文为 16 px，控件和辅助信息为 12–14 px。正文左对齐，阅读宽度上限为 740 px。常用圆角为 6 px，行之间用边线分隔。

- 使用 `.button.primary` 标识当前页面的主要操作，普通动作使用 `.button.secondary` 或 `.text-button`。破坏性操作使用明确的动作文案和确认对话框。图标按钮提供可读名称。
- 课程、对话和引用的选中行使用浅蓝底。处理中、失败和已就绪同时用文字表达。交互元素支持键盘可见焦点。
- 桌面共用左侧课程与对话导航。问答页的阅读栏由引用触发，资料库把文件列表与原文放在同一工作区。1179 px 及以下使用底部面板，800 px 及以下通过抽屉访问导航。
- 底部面板使用原生模态对话框，Esc 关闭后将焦点交回触发控件。确认对话框与阅读面板共用基本控件样式。
