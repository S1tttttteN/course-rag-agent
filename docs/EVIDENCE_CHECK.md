# 可选证据核对

`ANSWER_REVIEW=false` 为默认自然讲解模式，正文随生成实时显示。

设置 `ANSWER_REVIEW=true` 并重启后端后，生成草稿会先经过证据核对，核对完成后才发布正文；工具记录和状态仍实时展示。这适合希望回答更贴近检索材料的场景，会增加模型调用和等待时间。

## 核对过程

核对器把候选结论与已注册来源对应，返回支持情况、来源编号和原文摘录。程序拒绝不受支持、范围越界、引用未知、摘录不匹配或格式无效的条目，发布其余合格结论。

课程资料和网络来源保留类型区分。工具未取得正文时，目录或搜索摘要不能被当成完整课程或网页的全部内容。片段未提供某事实，不意味着整个资料库不存在该事实。

## 失败与限制

核对超时、格式无效或模型错误时，运行会失败并保留已取得来源，不发布未核对草稿。取消或重启也不会自动发布草稿。

核对仍依赖模型判断，程序只验证可机械检查的结构与摘录对应。它可能漏判或误删，不构成事实正确性保证；需要逐项阅读来源，尤其是课程专有参数、因果解释和跨资料结论。
